# TicSim

Modern endüstriyel dönemde, prosedürel üretilen ülke büyüklüğünde bir haritada geçen şirket üretim ve lojistik tycoon oyunu. Hedef: Song of Syx seviyesinde mikro simülasyon.

- **Motor:** Godot 4 + C#
- **Görsel:** 2D top-down
- **Mod:** Açık sandbox, tek oyunculu

## Durum

**Aşama 1 — Dünya simülasyonu (oyuncusuz).** Tasarım tamamlandı, kod henüz yazılmadı. Repo 2026-10-29'da eski ortaçağ ticaret prototipinden temizlendi; eski kod git geçmişinde duruyor.
